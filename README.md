| Learning Track | Main Topics |

| **C++ for DSA** | C++ fundamentals, functions, classes, objects and OOP |
| **Data Structures** | Arrays, linked lists, stacks, queues, trees, heaps, graphs and STL |
| **Algorithms** | Searching, sorting, BFS, DFS, shortest paths and dynamic programming |

## Software Engineering

Exploring practical software engineering concepts and modern application development practices.

### Core Engineering Concepts

- **Software Architecture:** Application structure, design patterns, modularity and maintainable code.
- **Authentication & Authorization:** User authentication, JWT, access control and secure sessions.
- **Database Concurrency:** Transactions, concurrent operations, data consistency and locking.
- **Caching:** Improving application performance through caching strategies.
- **Background Processing:** Handling asynchronous tasks and long-running operations.
- **API Security:** Secure API development, validation and access management.
- **Automated Testing:** Unit testing, integration testing and application reliability.
- **Deployment:** Application deployment, environment configuration and production setup.

These concepts connect programming fundamentals with the development of maintainable, secure and scalable applications.
